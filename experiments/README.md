# Experiments and measurements

Use this folder for procedures, raw data, and reproducible analysis. No measurements have been collected yet.

Suggested organization when measurements begin:

- `procedures/`: calibration and test steps, instruments, and acceptance criteria.
- `data/`: raw CSV measurements; preserve originals.
- `analysis/`: scripts and dependency instructions.
- `results/`: plots and concise interpretations used in the report.

For each run, record date, operator, board revision, firmware commit, motor/sensor, supply voltage, load, calibration, units, and measurement reference/uncertainty. Evaluate absolute positioning error, repeatability, stability, and response to commanded steps. Label provisional targets separately from achieved results.
