# Firmware

Embedded ESP32-S3 control software will live here. The framework and dependencies are intentionally pending motor, driver, and sensor selection.

Before the first implementation, document:

- Framework, compiler/SDK versions, target board, and dependencies.
- Reproducible build, flash, and serial-monitor commands.
- Pin assignments, sensor calibration, motor parameters, and configuration.
- Commissioning procedure, operating limits, and stop/disable behavior.

Keep code and reproducible dependency manifests in Git. Ignore local build outputs and generated dependencies. The unrelated C exercises in the course directory are not controller firmware and are not imported.
