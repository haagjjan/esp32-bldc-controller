\sectionlabel{Project Idea}
We aim to design, assemble, and program a custom ESP32-S3-WROOM-based PCB for precise closed-loop angular positioning of a brushless DC (BLDC) motor, using rotor-position feedback and field-oriented control (FOC) as the intended control strategy.
Together with the required motor-driving electronics, we plan to evaluate positioning accuracy and repeatability, provisionally targeting a steady-state absolute angular error of no more than \(\TargetAngle^\circ\) under no external load, subject to motor and sensor selection.
If the custom PCB cannot be commissioned successfully, we plan to use off-the-shelf controller boards with the necessary motor-driving and sensing components connected externally.
