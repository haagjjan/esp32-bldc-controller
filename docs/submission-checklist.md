# Report and demonstration handoff

Use this checklist before sharing a submission candidate. Confirm deadlines and submission requirements on the course platform.

- [ ] Complete member names and record each person's contribution.
- [ ] Replace scaffold prompts with the actual design, implementation, and results.
- [ ] Distinguish planned targets from measurements and state test conditions and uncertainty.
- [ ] Link hardware revisions, firmware commits, and the raw measurements supporting figures.
- [ ] Add references and attribution for reused material.
- [ ] Merge the final source changes and wait for Documents to succeed on main.
- [ ] Open the generated PDF and inspect all pages, figures, tables, and references.
- [ ] Save the submitted PDF and note the source commit and submission date.
- [ ] Rehearse a working hardware demonstration with participation from everyone.

GitHub does not submit documents to ADAM. A team member must complete the course submission.
