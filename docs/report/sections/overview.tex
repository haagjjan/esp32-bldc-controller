\section{Purpose and approach}
The project aims to develop a custom ESP32-S3-WROOM-based PCB for closed-loop angular positioning of a brushless DC motor, with rotor-position feedback and field-oriented control as the intended strategy.

The provisional target is a steady-state absolute angular error of at most \(1^\circ\) under no external load, subject to motor and sensor selection. This is not a measured result. Off-the-shelf controller boards are the planned fallback if the custom PCB cannot be commissioned.
